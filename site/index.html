    Windows may say "unknown publisher". The program is not signed with a paid certificate yet, so Windows warns about every new program like this.

    Click More info, then Run anyway. Use the installer for a normal install, or the portable file to run it from any folder without installing.

    On some new Windows 11 PCs Smart App Control blocks every unsigned program and offers no "Run anyway". It is under Windows Security, App & browser control, and once turned off it cannot be turned back on.

    Mac

    Which file do I need? Open the Apple menu, then About This Mac. If it says "Chip: Apple M…", choose Apple Silicon. If it says "Processor: Intel…", choose Intel.

    No Mac files in this version yet.

      The .dmg and the .zip hold the same app. Use either one, then drag Study Desk into Applications.

      The Mac app is not signed by Apple. macOS blocks it the first time, and you allow it once:

      • macOS 15 or newer: open Study Desk, press Done on the warning, then go to System Settings, Privacy & Security, scroll down and press Open Anyway.
      • macOS 14 or older: right-click (or Control-click) Study Desk, choose Open, then Open.
      • If it says the app is "damaged", run xattr -cr "/Applications/Study Desk.app" once in Terminal and try again.
